# Examples

Everything in this directory is simulated. None of it is real market data and
none of it is a credential.

| File | What it is |
| --- | --- |
| `instruments.json` | Reference data every service loads: two providers and six instruments. |
| `fixtures/session.ndjson` | A capture of both simulated venues: 7,998 frames exactly as they came off the wire, each with the ingestor's receive time. Generated by `make fixtures` from seed 42 with a fixed fault plan. |
| `fixtures/session.manifest.json` | The fault plan that produced the capture, its SHA-256, and what replaying it must produce (row counts, gaps, rejects and an output digest). `make replay` fails if any of it differs. |
| `entitlements.example.json` | Template for the gateway's entitlements file. The digests are all zeros and match no token. |

## Reference data

```json
{"provider": "alpha", "venue": "venueA", "seq_scope": "symbol", "trade_side": "aggressor", "seq_start": 1}
```

- `seq_scope`: `symbol` if the provider numbers each symbol separately, `feed`
  if one counter covers everything.
- `trade_side`: whether the provider's trade side is the `aggressor` or the
  `resting` order. The canonical schema always carries the aggressor.
- `seq_start`: the first sequence number of a session. Set it only if the
  provider guarantees it; it lets the platform notice that it joined a session
  late (see `docs/architecture.md`, "Joining a session late"). Leave it out or
  set `0` if unknown.

```json
{"instrument_id": "venueA:QRS", "venue": "venueA", "native_symbol": "QRS", "tick_size": "0.05", "lot_size": "0.001", "currency": "USD"}
```

`tick_size` and `lot_size` are decimal strings. Canonical prices are integer
multiples of `tick_size` and quantities integer multiples of `lot_size`; a
provider value that is not an exact multiple is rejected, not rounded.

## Replaying the capture

```sh
make replay        # in-memory pipeline; verifies counts and digest against the manifest
make fixtures      # regenerate; the files come out byte-identical
```

To push the capture through a running stack instead (it is labelled
`"source": "replay"` and is idempotent, so running it twice stores nothing new):

```sh
make deps-up
set -a; . ./.env; set +a
go run ./src/cmd/mdp ingest --replay examples/fixtures/session.ndjson
```

To record your own capture from the simulated venues, add `--capture <file>`
to `mdp ingest`.

## Entitlements

The gateway is open by default, which is appropriate only for local simulated
data. To require tokens, give it a file like `entitlements.example.json`. The
file holds SHA-256 digests, never tokens.

```sh
# 1. Make a token and keep it out of your shell history and out of this repo.
TOKEN=$(openssl rand -hex 32)

# 2. Put its digest in your copy of the file (not the example).
printf %s "$TOKEN" | shasum -a 256

# 3. Start the gateway with it.
MDP_ENTITLEMENTS_FILE=/path/to/entitlements.json mdp gateway

# 4. Call it. Tokens are accepted only in the Authorization header.
curl -H "Authorization: Bearer $TOKEN" 'http://127.0.0.1:8080/v1/instruments'
```

`"venues": ["*"]` grants every venue. A caller sees only instruments, events,
gaps and ingest health of venues it is entitled to: `401` without a valid
token, `403` for a venue it may not read.
